# カロリーマージ 〜二郎の頂〜

スイカゲーム風の物理マージゲーム。同じ食べ物同士を落として合体させると、より高カロリーな次の食べ物に進化する。最終的に「伝説の二郎」まで到達することを目指す、ネタ寄りの中毒性ゲーム。

React + Vite + Matter.js製。

- 公開URL: https://datemegane221.github.io/calorie-merge-game/
- `main`にpushすると`.github/workflows/deploy.yml`が自動でビルド・GitHub Pagesへデプロイする

## 遊び方

タップ / クリックで食べ物を落として、同じ食べ物同士を合体させよう。容器の上限ラインを超えて積み上がるとゲームオーバー。

## 進化テーブル

| 段階 | 名前 | カロリー(kcal) |
|----|------|------|
| 1 | 枝豆 | 15 |
| 2 | こんにゃく | 20 |
| 3 | おにぎり | 180 |
| 4 | から揚げ | 300 |
| 5 | 牛丼 | 700 |
| 6 | とんかつ | 900 |
| 7 | 焼肉 | 1200 |
| 8 | ラーメン | 700（あえてここで一度カロリーが下がる） |
| 9 | 二郎系ラーメン | 1500 |
| 10 | 二郎系マシマシ | 2500 |
| 11 | 二郎系アブラカラメマシマシ全部増し | 3500+ |
| 12(最終) | 伝説の二郎 | 実質1日の摂取カロリー相当 |

進化テーブルとカロリー数値は `src/game/foodConfig.js` に設定オブジェクトとして分離してあり、後で別テーマ（飲み会マージなど）に差し替えやすい構成にしている。

## 開発

```bash
npm install
npm run dev
```

`http://localhost:5173` で起動します。
